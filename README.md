## The entry

One funny single-line one-star review from a house cat about its human, under 200 characters:

> One star. My human bought a robot vacuum and named it before me. It gets thanked. I get told to move.

The complaint is specific and recognisable (the robot vacuum gets a name and thanks; the cat gets told to move), the voice is unmistakably feline — the human is measured by cat standards — and the sting lands in the last few words.

## Run

```sh
node main.ts
```

Writes the review to `/output/entry.txt`, validating the 1–200 character gate, the single-line rule and the round-trip first. Node 22+, standard library only.
